Reference AB - instalacija
==========================

WINDOWS
1. Zatvori Bitwig.
2. Kopiraj ceo folder "Reference AB.vst3" u:
      C:\Program Files\Common Files\VST3
3. Otvori Bitwig. Plugin se zove "Reference AB".

MAC
1. Zatvori Bitwig.
2. Raspakuj "Reference AB.vst3.zip" i kopiraj "Reference AB.vst3" u:
      ~/Library/Audio/Plug-Ins/VST3
   (u Finderu: Go > Go to Folder... i nalepi putanju)
3. Plugin nije potpisan Apple sertifikatom, pa jednom pokreni ovo u Terminalu:
      xattr -cr ~/Library/Audio/Plug-Ins/VST3/"Reference AB.vst3"
4. Otvori Bitwig. Plugin se zove "Reference AB".

Ako se plugin ne pojavi: Bitwig > Settings > Locations > Plug-in Locations,
proveri da je VST3 folder na listi i klikni Rescan.
